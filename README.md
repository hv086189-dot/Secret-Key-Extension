# SKIP Messaging Project

A Windows-based Java messaging project with KGC, multiple KPA servers, and peer nodes.

## 📌 Project Overview

This project demonstrates a secure messaging setup using:

- KGC (Key Generation Center)
- 6 KPA servers
- Peer Nodes
- Shamir module
- Java-based messaging

The project is designed to run locally on a Windows computer.

---

## 💻 Requirements

Before running the project, install:

- Windows
- Java JDK 8 or later

Make sure both Java and the Java compiler are available.

Open Command Prompt and check:

```cmd
java -version
javac -version
